🔤 Làm chủ 4 Thanh Điệu, Biến Điệu & Khẩu âm Đài Bắc

Tiếng Trung có 4 thanh chính + 1 thanh nhẹ. Người Đài Loan nói rất nhẹ nhàng, rõ chữ nhưng ít uốn lưỡi hơn Bắc Kinh. Hãy bấm vào từng thẻ để nghe trực tiếp!

🔄 3 Quy tắc biến điệu bắt buộc phải nhớ

1. Hai thanh 3 đi liền nhau (v + v → / + v)
Chữ đầu đọc thành thanh 2 (giống dấu sắc): 你好 viết là nǐ hǎo nhưng đọc là ní hǎo; 可以 đọc là ké yǐ.
2. Biến điệu của 不 (bù → bú khi trước thanh 4)
Bình thường đọc bù, nhưng đi trước thanh 4 đổi thành bú: 不要 (bú yào - không lấy), 不好意思 (bù hǎo yìsi).
3. Biến điệu của 一 (yī → yí hoặc yì)
Đứng trước thanh 4 đọc thành yí (一個 yí gè, 一下 yí xià); đứng trước thanh 1, 2, 3 đọc thành yì (一杯 yì bēi, 一起 yì qǐ).

🇹🇼 Bí kíp nghe & phát âm chuẩn Đài Bắc

• Phân biệt âm bật hơi (p, t, k, c, ch, q) và không bật hơi (b, d, g, z, zh, j)

Chữ b, d, g đọc giống p, t, c tiếng Việt (không bật hơi: bàba = pa-pa). Còn p, t, k phải bật luồng hơi mạnh ra khỏi miệng (tā đọc gần giống tha có hơi).

• Không uốn lưỡi 兒 (Erhua) như Bắc Kinh

Ở Đài Bắc, người dân nói 哪裡 (nǎlǐ) thay vì 哪兒 (nǎr), nói 這裡 (zhèlǐ) thay vì 這兒 (zhèr). Âm zh, ch, sh của người Đài cũng nhẹ hơn, gần với z, c, s nên nghe rất êm tai.

• Câu cửa miệng lịch sự ở Đài Bắc: 請問 (Qǐngwèn) & 不好意思 (Bù hǎoyìsi)

Khi bắt chuyện hỏi đường, gọi món hay hỏi giáo sư/học trưởng, người Đài luôn mở đầu bằng 不好意思，請問... (Xin lỗi làm phiền, cho mình hỏi...).

Triển khai Web App cá nhân miễn phí

🚀 Hướng dẫn đưa App lên GitHub Pages trong 1 phút

Ứng dụng này được thiết kế dạng Single-Page Static Web App (không cần server, lưu tiến độ học trực tiếp trên trình duyệt điện thoại/máy tính của bạn qua localStorage).

Bước 1: Tạo Repository

Tạo kho chứa mới trên GitHub

Đăng nhập vào GitHub, bấm New repository, đặt tên là taipei-mandarin, chọn chế độ Public rồi bấm Create repository.

Bước 2: Tải file index.html lên

Upload trực tiếp hoặc dùng Git

Bấm nút "⬇️ Tải file index.html" ở góc trên hoặc giải nén file .zip đính kèm, sau đó chọn uploading an existing file trên GitHub và kéo file index.html vào.

Bước 3: Bật GitHub Pages

Mở trên điện thoại mọi lúc

Vào Settings → Pages, ở mục Branch chọn main (thư mục /root) rồi bấm Save. Sau 30 giây bạn sẽ có link web riêng để ghim ra màn hình chính điện thoại!

# Hoặc đẩy code từ máy tính bằng Terminal:
mkdir taipei-mandarin && cd taipei-mandarin
# Đặt file index.html vừa tải vào thư mục này
git init
git branch -M main
git add index.html
git commit -m "Deploy Taipei Mandarin A1-B1 learning web app"
git remote add origin https://github.com/TEN_USER_CUA_BAN/taipei-mandarin.git
git push -u origin main
